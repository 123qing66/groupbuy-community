社区团购拼团系统

Spring Boot 3 + MyBatis-Plus + Redis + MySQL
小组项目 · 完整流程可交互演示
后端已连接 18 条接口契约 A 已实现 7 条

已真实联通的接口（A 活动域 + D 鉴权）

POST /api/auth/login　登录（BCrypt + JWT）
GET /api/auth/me　当前用户
POST /api/users/register　注册
GET /api/activities　列表·分页·动态条件
GET /api/activities/{id}　详情（含缓存）
POST /api/activities　开团（校验+初始化库存）
PUT /api/activities/{id}/status　状态机流转
GET /api/pickup-points　自提点
GET /api/health　健康检查
登录后会拿到 JWT，之后每个请求自动带 Authorization: Bearer 头；没登录点开团会看到 401。

尚未实现的链路（演示为模拟数据）

POST /api/orders　下单 Lua 预扣（B #7）
POST /api/pay/callback　支付回调成团（C #8）
POST /api/verify　核销提货码（C #10）
GET /api/stats/group-rate　成团率看板（C #16）
这些接口在 docs/api.md 里已冻结字段，队友照着写即可。演示页用本地模拟数据跑通完整链路，接口完成后把 MOCK 开关关掉就能直连。

演示控制

开团、状态流转、活动列表在后端运行时会写入真实 MySQL + Redis；下单/支付/核销暂由浏览器本地模拟。
